## 问题诊断结果

### 问题 2：候选逐项读值低 - **根因已确认**

**严重程度**: P0（最高优先级）

**现象**:
- 用户反馈："候选品的逐项参数对齐 6~8 项里只读到 0~2 项"
- 实测验证：多型号并列宽表 0% 读取率

**根本原因**:

当前 `configuration_alignment` 函数的逻辑（research_planning.py:1467-1468）：
```python
lines = [candidate_line.strip() for candidate_line in body.splitlines()
         if _is_candidate_family(candidate_line, query)][:200]
```

**只在"含候选型号的行"里匹配参数**，导致：

对于横向多型号表格：
1. 表头行含型号，但没有参数值
2. 参数行有值，但不含型号 → **被跳过**
3. 结果：参数值所在的行完全被忽略
4. **最终读取率：0%**

这正是"6~8 项里只读到 0~2 项"的**主要根因**！

**影响范围**:
- 产品参数页常见的多型号并列格式
- 厂商官网（如湘仪、海尔等）的系列产品对比表
- 估计影响 30-40% 的候选品配置读取
